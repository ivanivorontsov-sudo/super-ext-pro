# Super Ext Pro

Расширенная версия «СуперАпп» для Chrome / Edge / Яндекс Браузера (Manifest V3). Без телеметрии, всё работает локально.

## Установка
1. Распакуйте архив `super-ext-pro.zip`.
2. Откройте `chrome://extensions`, включите «Режим разработчика».
3. Нажмите «Загрузить распакованное» и выберите папку `super-ext-pro`.

Кнопка ⭐ Pro во всплывающем окне открывает все Pro-функции. Горячая клавиша окна — Alt+Shift+S.

## Всё из СуперАпп 1.1
Поиск и быстрая загрузка медиа (Range, 6 потоков) и HLS. Таблицы в CSV/JSON. Скриншоты (видимая часть, вся страница, область) с редактором. MHTML, HTML, PDF, TXT. Разблокировка копирования. PiP. Мобильный вид. Сессии вкладок. YouTube: петля, A-B, скорость, дизлайки.

## Pro
- **Вкладки:** менеджер с поиском, закрытие дубликатов, группировка и сортировка по сайтам, экспорт в CSV. Правила групп «домен → группа». Заморозка фоновых вкладок (вручную или по таймеру, с исключениями). Временные закладки на 1, 7 или 30 дней. Автосохранение сессий раз в 30 минут.
- **Страница:** тёмная тема для любого сайта (запоминается для сайта). Режим чтения. Линейка. Автообновление. Скорость видео до 16× на любом сайте (Shift+. / Shift+, / Shift+0). PiP. Свой CSS и JS для сайта. Просмотр, удаление и экспорт куки, localStorage и sessionStorage. archive.org: сохранить снимок или посмотреть снимки.
- **Медиа:** HLS (.m3u8) → MP4. Сегменты качаются параллельно, AES-128 расшифровывается, поток перепаковывается через mux.js. Очередь загрузок с ограничением параллельности.
- **Инструменты:** офлайн OCR (tesseract.js, русский и английский) по снимку вкладки или из файла. Создание и распознавание QR-кодов. Пипетка (EyeDropper или по снимку). Перевод выделенного текста через контекстное меню.
- **Блокировка:** около 50 рекламных и трекинговых доменов через declarativeNetRequest, включая Метрику, GA, Criteo и Taboola.
- **Заметки:** заметки к каждому сайту, экспорт в Markdown.

## Ограничения
DRM (Widevine, SAMPLE-AES) и потоки YouTube не скачиваются. Блок-лист базовый: для полной фильтрации используйте вместе с uBlock Origin Lite. Свой JS не работает на сайтах со строгим CSP. Перевод открывает Google Translate, туда уходит только выделенный текст и только по вашему клику.

Библиотеки: tesseract.js (Apache-2.0), mux.js (Apache-2.0), jsQR (Apache-2.0), qrcode-generator (MIT).
